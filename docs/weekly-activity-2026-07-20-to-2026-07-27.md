# Weekly Activity Report — 2026-07-20 to 2026-07-27

## Summary

This week focused on expanding guest checkout capabilities, adding delivery/promotional logic, and improving payment indexer robustness.

## Completed Activities

### Guest Checkout & Cart
- Implemented `POST /api/cart/checkout` (public) and `POST /api/cart/wallet` (public) for unauthenticated purchasing in `app/Controllers/Http/CartController.ts`
- Refactored checkout to calculate delivery fees and discount logic (promo codes + percentage discounts) before creating `PaymentIntent`
- Added `POST /api/user/cart/checkout` and `POST /api/user/cart/wallet` auth-based endpoints for logged-in users
- Added cart clear and item removal endpoints

### Delivery Settings
- Added `ShopDeliverySetting` model and `ShopDeliverySettingController`
- Created migration `20260723120000_create_shop_delivery_settings.ts`
- Shop owners can now configure per-shop delivery fees, delivery zones (state-based), free delivery toggle, and free delivery thresholds
- Added public `GET /api/shop/:subdomain/delivery-settings` endpoint

### Payment Intent Enhancements
- Added `customerId` and `customer_email` fields to `PaymentIntent` via migration `20260722150500_add_customer_to_payment_intents.ts`
- Added `metadata` JSONB field to `PaymentIntent` to store checkout breakdown (items_total, delivery_fee, discount_amount, delivery_address, etc.)
- Linked guest payments to customers by email

### Email Notifications
- Added `customer_order_confirmed.html` template
- Updated `EmailNotificationService.ts` to send order confirmation to customers (previously only businesses were notified)
- Payment processing and failure email templates already in place

### Payment Indexer
- Enhanced `PaymentIndexerService.ts` to better track payment statuses
- Improved webhook/dispatcher resilience

### Shop Builder
- Updated `routes/user/shop_builder.ts` to support new cart/checkout flows
- Maintained backward compatibility with existing shop builder endpoints

### SSE Events
- Cart events (`cart.item_added`, `cart.removed`, `cart.updated`, `cart.cleared`, `cart.checkout_completed`) emitted via `SseService` for logged-in users

### Documentation
- Added `docs/frontend-changes-guest-checkout-delivery-promos.md` — full frontend integration guide for guest checkout, delivery, promos, and cart
